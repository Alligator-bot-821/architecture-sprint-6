Жесткая связанность сервисов, увеличивает вероятность отказа из за проблем любого из узлов.

Синхронный запрос через все сервисы что опять же приводит к большим рискам возникноверия ошибки 
на любом из вызовах к сервисам, при долгом ответе запрос может завершиться по таймауту. Также ошибка может произойти 
при обращении к внешнему сервису он может быть не доступен, а запрос выполняется синхронный.

Локальные реплики данных, обновляются в разное время и происходит несогласованность данных, в добавок такое решение 
не даст горизонтального масштабирования сервиса
